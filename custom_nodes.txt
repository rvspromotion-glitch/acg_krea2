# ── Upscale / restoration pass ──
# SeedVR2, the diffusion-transformer restorer, as the final quality pass. Takes
# the krea2 output and rebuilds detail rather than interpolating it, which is
# what an ESRGAN-family upscaler does.
#
# numz is upstream. Comfy-Org mirrors the identical codebase at
# comfyorg/comfyui_seedvr2, but that mirror sits two months behind, so point at
# the source. It needs models of its own — see the SEEDVR2 block in models.txt.
#
# It registers itself through ComfyUI's V3 extension API (comfy_api.latest
# ComfyExtension), which our pinned COMFYUI_REF=v0.32.0 exports. If you ever
# move that pin backwards, check that first: the failure is an import error at
# boot, not a missing node.
ComfyUI-SeedVR2_VideoUpscaler  numz/ComfyUI-SeedVR2_VideoUpscaler        HEAD

# ── First-party realism pass ──
# ACG Realism Nodes: ACGRealismStack (all-in-one), ACGCameraRaw, ACGSkinDetail,
# ACGSkinMask, ACGContactShadows, ACGPhoneColor, ACGDepthDefocus.
#
# Costs the build nothing: one package at the repo root, no requirements.txt,
# and it imports only cv2, numpy and torch, all of which are already here.
#
# It does depend on the opencv work though. ops.py reaches for
# cv2.ximgproc.guidedFilter, which only the contrib build ships — and it wraps
# that in a try/except that falls back to bilateralFilter, so against a plain
# opencv it does not fail, it just quietly produces a worse result. That is the
# second consumer of the contrib build after LayerStyle, and the reason the
# normalisation at the end of install_nodes.sh has to stay.
ACG_Realism_Nodes           rvspromotion-glitch/ACG_Realism_Nodes     HEAD
