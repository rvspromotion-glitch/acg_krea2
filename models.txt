# Models fetched on first boot, into MODELS_DIR (default /workspace/models).
#
#   hf     <repo>  <path-in-repo>  <dest under MODELS_DIR>
#   civit  <url>                   <dest under MODELS_DIR>
#
# Blank lines and #-comments are ignored. Destination filenames are what the
# graphs in workflows/ reference — renaming one here without renaming it in the
# JSON breaks the render, not the download.
#
# These are deliberately NOT baked into the image: ~50GB of weights on top of
# torch does not build on a hosted GitHub runner. On a pod that costs nothing
# after the first boot, because /workspace is a persistent volume — the fetch is
# skip-if-present, so restart #2 onwards starts in seconds.
#
# Sizing: give the pod a volume of at least 100GB.

# ── SeedVR2, the upscale / restoration pass ──
#
# Every model the node can load is listed here, active or commented, because
# anything NOT pre-fetched gets pulled by the node itself at render time — you
# see it as "Downloading /opt/ComfyUI/models/SEEDVR2/… from huggingface.co" in
# the middle of a job. Switching model is therefore a one-line uncomment here,
# not a surprise download later.
#
# Filenames are load-bearing twice over: the node resolves these by exact name
# in models/SEEDVR2 and checks each against a sha256 in its own registry, so a
# renamed file reads as missing, not as wrong. (The hashes match: HF serves
# seedvr2_ema_3b_fp16 as 2fd0e03a…, which is what the registry expects.)
#
# Active set is ~10GB:
